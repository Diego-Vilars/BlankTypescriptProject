Para rodar o codigo no vscode:

Abrir terminal bash ou cmd:

npm install

npx expo start

Confirmar pergunta do terminal:

y

Escolhendo a plataforma para roda:

Caso tenha "Expo Go" em seu celular e na mesma rede ou "Studio Android" instalado:

a

Caso der erro verificar se as versões estão compativeis. Caso alguma de errado conferir documentação https://docs.expo.dev/.
